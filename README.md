# FTC Advancement Calculator

With the new advancement points introduced in FTC in 2025, I was curious about how the system would have translated in previous years' advancements. This program will calculate the points that teams at a given competition would get using the 2025 points ranking system. The calculation follows the specifics detailed in the 2025 competition manual, with small tweaks depending on the year.
